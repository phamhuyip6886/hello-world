# hello-world

Repo thực hành Git & GitHub đầu tiên của tôi.

## Các lệnh Git hay dùng

```powershell
git status              # xem trạng thái thay đổi
git add .               # chọn tất cả file để lưu
git commit -m "ghi chú" # lưu snapshot vào lịch sử
git log --oneline       # xem lịch sử commit
git push                # đẩy lên GitHub
git pull                # lấy code mới từ GitHub
```
